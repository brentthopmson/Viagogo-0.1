# Design Specification: Viagogo Rebranded

This document defines the visual and behavioral requirements for the Viagogo platform, focusing on a clean, modern, and match-centric mobile experience.

## 1. Global Components

### 1.1 Bottom Navigation Bar (Mobile)
- **Background**: Solid `#FFFFFF` (White).
- **Border**: Top border `#F4F7F9` (1px).
- **Height**: ~64px.
- **Active State**: Icon and label color `#89CF28` (Viagogo Green).
- **Inactive State**: Icon and label color `#8E8E93` (Gray).
- **Items**:
  - **Discover**: `faSearch` | "Discover"
  - **Favorites**: `faHeart` | "Favorites"
  - **My Tickets**: `faTicketAlt` | "My Tickets"
  - **My Account**: `faUserCircle` | "My Account"

### 1.2 Header (Standard)
- **Background**: `#FFFFFF` (White).
- **Branding**: Viagogo Logo (SVG) centered or left-aligned.
- **Actions**: "Help" link and User Icon.

## 2. Page: Ticket Management

### 2.1 Tab System
- **Labels**: "ACTIVE" and "COMPLETED".
- **Style**: Bold, sans-serif, uppercase.
- **Active Indicator**: Thick `#89CF28` bottom border.

### 2.2 Ticket Cards
- **Style**: High-contrast, card-based layout.
- **Hero Image**: Clear match/event branding.
- **Details**:
  - Title: Event name in bold navy.
  - Subtitle: Date and Venue in gray.
  - **Seat Info**: Displayed prominently in a structured grid.

## 3. Colors & Typography

### 3.1 Color Palette
- **Primary Green**: `#89CF28`
- **Dark Navy**: `#001B41`
- **Soft Gray**: `#F4F7F9` (Backgrounds)
- **Border Gray**: `#E5E7EB`

### 3.2 Typography
- **Font**: Sans-serif (Open Sans or Roboto).
- **Headings**: Navy, Bold, tight letter spacing.
- **Body**: Gray, regular weight.
